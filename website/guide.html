YOUR FIRST MOVE

Get connected.
Go elsewhere.

The new design is in development. This guide explains the app’s setup; it is not a download or a promise that a particular signing service supports your device.

01 / Install

  1. When a tested build is available, download the IPA from its official distribution link.
  2. Sideload with your signing service. Keep the companion extension if you want widgets and Live Activities.
  3. Export a backup before replacing an existing installation. Installing over it with the same app identity and signing setup helps preserve its data.

02 / Pair your iPhone

  1. Join Wi-Fi, install LocalDevVPN, and connect it.
  2. Open the app’s setup checklist. The standard tunnel address is 10.7.0.1.
  3. If Pair on this iPhone is offered, follow the in-app instructions. Enter your device passcode only in the iPhone’s own system prompt.
  4. Otherwise, create an RPPairing file with idevice_pair on your computer, then import or paste it into the app. A SideStore pairing file is a different format.
  5. Complete Check connection. Keep pairing files private.

03 / Make your first move

Search for a place, inspect the pin, then tap Teleport. For a journey, choose a route and review it before starting. Stop waits support hours, minutes, and seconds, up to 24 hours.

Stop spoofing requests clearing the simulated location. If clearing fails, reconnect and retry. Closing the app does not prove the location was cleared.

Make it yours

Open Settings → Appearance. Ion uses a dark palette and solid surfaces by default. Choose a different color mode, surface, font, or text size—or use the theme defaults. App icon choices are independent.

Check for a new version

Open Settings → Software updates → Check for updates now. The app checks official releases, with no automatic download. If GitHub asks it to wait, it will show when you can retry.

Optional cloud checks

These need a separately configured helper and your own provider account. A provider’s latest reported location can be stale. Find My Devices is distinct from Find My People; Find My People is not connected in this version. Keep credentials and helper tokens out of screenshots, backups, and public repositories.
