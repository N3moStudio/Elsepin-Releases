# Backups and imports

Open **Settings → Import & export**. Choose a backup file or paste its JSON text. If Files cannot select the file, open it in an editor, copy the text and use **Paste backup text**. The optional [json.site](https://json.site) link opens a third-party editor; decide whether you want to open your location data there.

The import overview shows what would change compared with your current settings and library. Review the individual settings, places, routes and areas, then deselect anything you want to keep. Different settings appear first. Nothing changes until you confirm.

Export **Everything**, **Settings**, or **Saved routes and areas**. New backups include theme, surfaces, font and relative text size. Earlier compatible library backups still work. Credentials, pairing files and cloud tokens are excluded from portable settings.

Avoid importing while a route is running; the app will explain when the active operation needs to stop. Keep your backup somewhere private. Test importing a copy before relying on it as your only backup.
