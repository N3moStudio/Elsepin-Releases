# Elsepin 2.6.1: Routes, places and a calmer map

**Unpublished draft.** Covers development builds 60–86. Final iPhone testing is in progress; 2.6.0 remains the public release. No release IPA is attached yet.

## Plan the whole journey

Choose the movement mode and speed for each route leg. Keep the current path or recalculate when changing modes, search within another city or along the route, and preview the map before starting. Bike and e-bike planning tries cycling directions first and clearly labels a walking-path fallback when cycling directions are unavailable.

Set waits at each stop and arrival behavior at the destination. Prepare a next route with an optional wait and one-time automatic start, or cancel it without stopping your current trip. Planned routes reopen from Recents, ordinary map taps keep the preview intact, and failed starts preserve it when no location was sent.

## Save a place, favorite it when you want

- Save to Library or Save & Favorite. Unfavoriting keeps the saved pin or route, and the map star updates the existing route instead of creating a separate favorite.
- Customize pins with symbols, one native emoji, fixed colors or Follow theme. Save stays disabled until a pin has a location and name.
- Edit pins and areas on larger maps, with an explicit full-screen button and search. Pin editing opens near the saved point; Library pin creation no longer shifts around while looking up an address.
- Undo and Redo area corners. Swipe to favorite, delete or restore, and drag through Recently Deleted to select multiple rows.
- Review backup additions and individual setting changes before importing. Existing library identities and older backups remain compatible.

## See more of the map

Adjust pin size and how far out saved pins remain visible, from 0.5 to 20 miles across the map. A native scale sits below the map controls. Pin visibility now updates during zooming in either direction and stays consistent when the map rotates.

The bottom panel is smaller, with corrected spacing above the tab bar. Controls wrap on narrow screens, long route details can scroll, and Pause/Stop stay reachable. Search distinguishes pins from saved routes; pin names remain available during a journey.

## Pairing and recovery fixes

Pairing progress and the code appear through the available in-app, notification and Live Activity surfaces. Cancelled attempts release their work, ignore late callbacks and cannot overwrite a newly imported pairing file. Retry has a bounded cleanup wait and clearer recovery text.

Connection checks use fresh evidence before explicit movement and Stop. Eligible interrupted routes get one foreground recovery attempt and resume only after the saved point is accepted. Uncertain and failed clears remain visible instead of claiming that the phone returned to GPS.

This cycle also fixes the saved-pin annotation crash identified from a device report, the route-planner search-bar overlay, garbled text, destination/add-stop controls and several map-input edge cases. Further device testing is still in progress.

## Personalize and troubleshoot

Eight themes, thirteen icons, Bloom as the new default, and Solid or Liquid Glass surfaces. Settings and route editors use simpler groups with fewer nested cards, while preserving accessibility text and transparency fallbacks.

Dev Mode opens an isolated demo library and returns your real data when disabled. Opt-in developer logs include bounded resource samples, session events and incident notes. Reduced background/map work and static low-power feedback help avoid unnecessary work; battery performance still depends on the device and session.

## Before updating

Export a library backup and keep the same signing setup where possible. Elsepin needs a compatible iPhone, Wi-Fi, LocalDevVPN and a valid pairing connection. Widget features also depend on the signing capabilities available to the installation.

If Elsepin can't clear the location, connect to Wi-Fi, reconnect LocalDevVPN, and try again. Another device's Wi-Fi hotspot can also work. Closing or force-quitting Elsepin doesn't confirm that it cleared. Check another app too.

Existing Find My Devices/Life360 helper checks remain experimental in build 86. The proposed replacement Life360 map integration is not part of this release, and Find My People is unsupported.

## Validation and release status

Build 86 passed 724 automated checks and compiled the app and extension without compiler warnings or errors. Fourteen distinct simulator UI cases passed across focused runs. Simulated connection/session states do not establish real-device spoofing, signing, recovery or battery behavior.

Publication is waiting for final physical-iPhone acceptance and the verified official-channel IPA. This draft does not announce availability.
