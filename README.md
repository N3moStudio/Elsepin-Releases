# Elsepin

Official downloads, release notes and setup help. Application development is private; this repository contains no app source, accounts, pairing records or cloud credentials.

The Elsepin redesign is in development. **No new Elsepin IPA has been published yet.** Approved versions will appear under [Releases](https://github.com/N3moStudio/Elsepin-Releases/releases).

- [Optional cloud checks and Nearby alerts](docs/CLOUD-GUIDE.md)
- [Licenses and acknowledgments](LICENSES.txt)

Find My Devices and Life360 checks need a separate helper and authorized accounts. They are optional and experimental. Find My People is not connected in this version. A location report can be stale; a successful connection is not proof another app has accepted the simulated location.

## Updates

In the new app, use **Settings → Software updates → Check for updates now**. Automatic checks run at most once a day while the app is open. Only official releases are considered; no account token is built into the app.

## Distribution

Download only a version you intend to install, back up first, and keep the Live Activity extension when signing. Required open-source notices remain included. A new name or private development repository does not revoke permissions already granted to inherited or previously released code.
